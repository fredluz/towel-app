# Upper-body example

This file is deliberately ordinary Markdown. Towel does not require a schema.

## Session

- [ ] Shoulder circles — 20 seconds
  - Start once I say I am ready.
  - Announce: “Ten seconds left.”
  - At the end say: “Shoulder circles done.”

- [ ] Bench press
  - Warm-up: 20 kg × 10
  - Work: 3 × 8 at 80 kg
  - I may count reps aloud or report each set afterward.
  - After each work set, ask how it felt before deciding what the document says next.

- [ ] Barbell row — 3 × 10 at 60 kg
  - Alternate with bench if the bench section says to do so.

- [ ] Hamstring stretch — 30 seconds per side
  - Wait for “ready” before each side.
  - Announce: “Fifteen seconds.”
  - At the end say which side is complete.
